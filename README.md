# barphone

Аналог Stream Deck из смартфона: на компьютере настраиваете кнопки, на телефоне нажимаете — на компьютере открывается программа, файл или ссылка. Связь по локальной сети.

- **Свайп вверх** на деке — недавние запуски с деки.
- **Свайп вниз** — список компьютеров, к которым подключён телефон; тап переключает деку.
- **Не только программы:** сочетания клавиш (`Ctrl+Shift+P`, `Win+D`, запись сочетания прямо в настройке), ввод текста, медиа (пауза, треки), громкость, без звука, блокировка, сон, выключение экрана, выключение и перезагрузка ПК (только с подтверждением на телефоне). У кнопки «Громкость» тап выключает звук, а удержание и ведение пальцем меняет громкость. «Яркость» (Windows: экран ноутбука и мониторы с DDC/CI) — тем же жестом, плюс кнопки «Ярче» и «Темнее».
- **Профили:** несколько дек, например «Основной» и «VS Code». Профиль привязывается к приложениям, и телефон сам переключается на него, когда это приложение впереди на ПК. В шапке деки на телефоне плашка профиля: можно закрепить любой или вернуть «Автоматически». Агент запоминает только какие приложения были впереди (в памяти, без заголовков окон).
- **Папки:** кнопка-папка открывает на телефоне свои кнопки, первая плитка — «назад». На ПК: «+» → «Ещё» → «Папка»; кнопку кладут в папку, перетащив её на середину папки, или через «Где лежит» в настройке кнопки.
- **Макросы:** одна кнопка выполняет цепочку шагов с паузами — открыть программы и ссылки, нажать клавиши, вставить текст, медиа. На ПК: «+» → «Ещё» → «Макрос», дальше «+ Действие» и «+ Пауза». Уже открытая программа выводится вперёд; выключение и перезагрузку в макрос добавить нельзя.
- **Таймер** (например, Pomodoro): тап — старт, на плитке обратный отсчёт; ещё тап — остановить (спросит). Когда время выйдет, телефон завибрирует и покажет сообщение. Отсчёт идёт на телефоне, работает и без связи с ПК. На ПК: «+» → «Ещё» → «Таймер».
- **Живые плитки:** загрузка процессора и занятая память ПК прямо на деке, обновляются каждые ~2 с (только пока телефон подключён). Тап — диспетчер задач. На ПК: «+» → «Ещё» → «Живые плитки».
- **Трекпад и клавиатура:** кнопка «Трекпад» открывает на телефоне сенсорную панель — палец водит курсор, тап — щелчок, два пальца — прокрутка, тап двумя пальцами — правый щелчок; клавиатура телефона печатает на ПК, есть Esc, Tab, стрелки. Управление мышью включается только добавлением этой кнопки на ПК («+» → «Ещё»). На macOS пока только клавиатура.
- **Команды:** кнопка запускает строку как в консоли (`git pull`, `npm run build`, `backup.bat`) в заданной папке — в видимом окне консоли, по желанию с подтверждением на телефоне. Когда команда закончится, на телефон придёт уведомление «Готово» или «Ошибка (код N)». Команду можно сделать и шагом макроса.
- **Уведомления на телефон** от своих скриптов: `barphone-agent -notify "Сборка упала" -title "CI" -level error` или `POST http://127.0.0.1:47801/api/notify` с заголовком `X-Barphone-UI: 1` (только с этого ПК). Телефон показывает их поверх деки.
- **Звонок Google Meet** (Windows): если подключён один компьютер и на нём идёт звонок, в горизонтальном положении вторая половина экрана — пульт звонка: микрофон, камера (видно, включена ли), «поднять руку», «открыть Meet». Агент на мгновение выводит окно Meet вперёд, нажимает его сочетание (Ctrl+D, Ctrl+E, Ctrl+Alt+H) и возвращает ваше окно. Отключается галочкой в карточке «Этот компьютер».
- **Виртуальные рабочие столы:** плитка «Рабочие столы» показывает, какой стол открыт («2 / 5», точки или имя стола); свайп по ней влево/вправо листает столы, тап — обзор всех окон и столов, удержание — список столов, тап по столу — сразу туда. На экране трекпада то же самое тремя пальцами: ← → — столы, ↑ — обзор. Есть и отдельные кнопки «Следующий/Предыдущий рабочий стол», «Обзор» (годятся для макросов). На ПК: «+» → «Система». Windows переключает столы как Win+Ctrl+←/→; на macOS — Ctrl+←/→ (без номера стола на плитке).
- **Если приложение уже открыто** (Windows; окна всех рабочих столов считаются как будто стол один — к окну на другом столе телефон переключает вместе со столом): одно окно — телефон переключает на него, а если оно уже впереди — сворачивает (кнопка работает как переключатель). Несколько окон (например, 4 окна VS Code с разными проектами) — телефон показывает их плитками с заголовками, окно, которое сейчас впереди, помечено; тап по нему сворачивает, плюс «Запустить новый» и «Свернуть все». **Долгое нажатие** на кнопку всегда открывает этот выбор. В настройке кнопки на ПК можно выбрать «Всегда запускать новое».
- **Иконки ссылок** агент берёт с самого сайта (apple-touch-icon / favicon). Чтобы обновить иконку у старой кнопки-ссылки — «Сбросить» у иконки в её настройке на ПК.
- **Два компьютера на одном экране:** в горизонтальном положении, когда подключены два компьютера, дека делится пополам — слева выбранный, справа второй. У каждой половины свой профиль и вдвое меньше колонок, остальные кнопки листаются вбок внутри половины. Число «колонок» из настройки деки — это сколько плиток помещается вдоль короткой стороны телефона: в горизонтальном положении это строки.

```
 [Телефон: Flutter-приложение] ──WebSocket (LAN, :47800)──▶ [barphone-agent на ПК] ◀── браузер: http://127.0.0.1:47801
```

## Агент (компьютер)

Сборка (нужен Go 1.26+):

```sh
cd agent
# Windows: без консольного окна
go build -trimpath -ldflags "-s -w -H=windowsgui" -o dist/barphone-agent.exe ./cmd/barphone-agent
# macOS (на Mac, для иконки в строке меню нужен cgo — он включён по умолчанию)
go build -trimpath -ldflags "-s -w" -o dist/barphone-agent ./cmd/barphone-agent
```

На Mac удобнее собрать приложение: `./build-macos-app.sh` → `dist/barphone.app` под архитектуру этого Mac (Intel или Apple Silicon), с иконкой, без значка в Dock — только в строке меню. Нужны Xcode Command Line Tools (`xcode-select --install`). Подпись ad-hoc: работает на том Mac, где собрано. Разрешения macOS (Универсальный доступ — для сочетаний клавиш и ввода текста, Автоматизация — для System Events) выдаются самому barphone, а не Терминалу; после пересборки «Универсальный доступ» для barphone может понадобиться выключить и включить заново.

Первый запуск:

1. **Положите exe туда, где он будет жить постоянно** (например, `%LOCALAPPDATA%\barphone\`; на Mac — `barphone.app` в «Программы») — правило брандмауэра и автозапуск привязаны к пути.
2. Запустите. Откроется `http://127.0.0.1:47801` — там настройка деки. Значок в трее: клик — настройки, меню — «Подключить телефон», «Выход».
3. В карточке «Этот компьютер» агент показывает, пропускает ли брандмауэр Windows телефоны. Windows 11 помечает новые сети как «общедоступные» и блокирует входящие — нажмите **«Разрешить подключения»**. Windows спросит права администратора для barphone-agent: он перезапускается с ними и через COM-API брандмауэра заменяет правила своего exe (сопоставление по точному пути) одним разрешающим. Вручную то же самое: Панель управления → Брандмауэр Защитника Windows → «Разрешить взаимодействие с приложением» → barphone-agent.exe, частная и публичная сеть.
4. Там же можно включить «Запускать при входе в систему».

Флаги: `-lan :47800`, `-ui 127.0.0.1:47801`, `-config-dir <папка>`, `-no-browser`, `-no-tray`.
Конфиг, иконки и лог — в `%APPDATA%\barphone` (macOS: `~/Library/Application Support/barphone`).
При первом запуске версии с профилями старый `config.json` переносится в профиль «Основной», а исходный файл сохраняется рядом как `config.v1.bak.json`.

## Приложение (Android)

```sh
cd app
flutter build apk --release --split-per-abi     # ~20 МБ на архитектуру вместо 65 МБ универсального
adb install -r build/app/outputs/flutter-apk/app-arm64-v8a-release.apk   # большинство современных телефонов
```

Подключение: на ПК «Подключить телефон» → в приложении «Добавить компьютер» → навести камеру на QR.
Без камеры: ввести IP и 6-значный код вручную, или выбрать компьютер из «Найдены в сети» (mDNS).
QR-код — это ссылка `barphone://pair?...`, поэтому его можно отсканировать и системной камерой.

Приложение работает на весь экран и не даёт экрану гаснуть. Для выключенного компьютера в списке есть «Разбудить» (Wake-on-LAN, если включён в BIOS/сетевой карте).

Если связь с компьютером на миг пропала, дека остаётся как была: приложение переподключается в фоне, а нажатие в это время дожидается связи. Только если компьютер не вернулся за ~45 с, дека тускнеет и появляется «Нет связи».

## Безопасность

- Телефон не передаёт ни путей, ни команд — только `id` кнопки, настроенной на ПК. Исключение — трекпад: свободный ввод мышью и с клавиатуры агент принимает, только пока на деке есть кнопка «Трекпад».
- Сопряжение — одноразовый 6-значный код (5 минут, сгорает после 5 неверных попыток) → постоянный токен; на ПК хранится только его хэш. Отключить телефон можно в настройках, он сразу теряет доступ.
- Настройка доступна только с самого компьютера (`127.0.0.1`), с защитой от DNS rebinding и запросов со сторонних сайтов.
- **Шифрование:** агент создаёт свой сертификат, его отпечаток (SHA-256) идёт в QR-коде. Телефон, подключённый по QR, сразу общается по TLS (HTTPS/WSS на том же порту 47800) и доверяет только этому сертификату. Телефоны, сопряжённые раньше или вручную по коду, узнают отпечаток из первого подключения и дальше переходят на TLS сами. После первого успешного TLS-подключения телефон больше никогда не ходит к этому ПК открыто. Если сертификат сменился (переустановка агента или подмена), телефон покажет «Компьютер не узнан» и попросит подключить заново. Сертификат хранится в папке конфига (`tls-cert.pem`, `tls-key.pem`) — при переносе агента копируйте их вместе с `config.json`.

## Тесты

```sh
cd agent && go test ./...                         # протокол целиком на фейковом лаунчере
cd app && flutter test                             # модели, раскладка сетки, WoL, экраны (выбор окна, профили, две деки)

# ручные проверки на Windows (тег manual; открывают и сами закрывают маленькие окна):
cd agent && go test -tags manual -v ./internal/launch                 # список приложений, иконки, передний план, поиск и переключение окон (tools/probewin)
# против запущенного на этом ПК агента:
cd agent && go test -tags manual -v -run E2E ./internal/server        # сопряжение + запуск по LAN-адресу, как телефон
cd agent && go test -tags manual -v ./internal/discovery              # mDNS — только когда брандмауэр пропускает агента
cd app && BARPHONE_LIVE=1 flutter test test/live_agent_test.dart       # Dart-клиент протокола против живого агента (и TLS)
#   + BARPHONE_PROBE=<путь к собранному tools/probewin.exe> — выбор окна на настоящих окнах;
#   BARPHONE_UI=http://127.0.0.1:47901 — если тестовый агент запущен на других портах (-lan :47900 -ui 127.0.0.1:47901)
```
